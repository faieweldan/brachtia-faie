# Brachtia Homes

Build a modern responsive website for a student accommodation company.

Match the colours and company write up to the Company Profile attached, I want a section to also show like google reviews.

Students should be able to browse properties (there's 2 for now), click into a property to see photos, facilities and amenities, view room pricing for 12-month and short-term stays, see available units/rooms, and click into a specific room.

Each room should show monthly rent, occupancy option (single or twin sharing), availability date and a breakdown of deposits/upfront costs.

Include CTAs to Book a Viewing, Apply, and Contact via WhatsApp.

For now, use realistic sample data and focus on creating a clean, trustworthy, mobile-friendly student accommodation browsing experience. We will build the admin backend and connect the data later.
